# Your notes

Writing about code is most of what a senior engineer actually does, and it's
what interviews test. This folder is where you practise it.

| File / folder | What goes in it |
| --- | --- |
| `stuck-log.md` | What broke, what you expected, what you tried. Gates `./ttt reveal`. |
| `interview/` | One short answer per stage, written **before** you look anything up. |
| `reviews/` | Your findings when you review code — someone else's at Stage 5, your own at Stage 7. |

Nobody grades these. They're for you — and they're the raw material for
answering "tell me about something you built" without freezing.
